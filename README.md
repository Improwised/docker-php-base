# docker-php-base

Base image for pos-back-office  

Contains: 
- php-8.2 with s6-overlay  
- gRPC package 
- A oneshot process 'apply-env' that replaces the env at runtime on container start 

### About apply-env oneshot process: 
env that are used at build time when running `npm run build` needs to be replaced at run time  
apply-env is a oneshot process that runs only onetime when container starts, it runs a script that replaces the envs defined in the script with the one that are provided at runtime (see apply-env/run)  
The script searches for the env defined in the script in each file at path defined by HTML_PATH, make sure to pass it during runtime.  
In this case env needs to be replaced in files generated by `npm run build`, so 
HTML_PATH=/public/build/assests needs to be passed to container using env or configMap.
